# PokerDriller Pro v3.1

Adaptive Beginner-to-Pro GTO Poker Trainer & Live Monte Carlo Equity Solver.

**Live Demo:** [good-enough-productions.github.io/pokerdriller](https://good-enough-productions.github.io/pokerdriller/)

## Highlights

- **GTO Drill Trainer** — Practice preflop and postflop spots with adaptive difficulty from beginner to advanced.
- **Live Monte Carlo Equity Solver** — Real-time hand vs. range equity calculation and odds breakdown.
- **Interactive Analytics** — Session performance charts powered by Recharts.

## Tech Stack

- React 19 + Tailwind CSS + Recharts
- Static SPA hosted on GitHub Pages
